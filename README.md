# 🏍️ MotoLog - Personal Garage & Fuel Tracker

A lightweight, zero-cost garage management web application that runs directly in your browser using `localStorage`.

### 🚀 Deploying to GitHub Pages in 3 Steps:
1. Create a new GitHub repository named `motolog` (or any name you prefer).
2. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
3. Go to **Repository Settings** $\rightarrow$ **Pages** $\rightarrow$ Under **Branch**, select `main` (or `master`) and hit **Save**.
4. Open the generated GitHub URL on your phone or PC browser. Bookmark or use *"Add to Home Screen"* on mobile for an app-like experience!
